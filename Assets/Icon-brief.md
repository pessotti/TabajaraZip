# Ícone Tabajara ZIP

Arte criada com o gerador de imagens integrado. Fonte: Tabajara-AppIcon.png. A geração original foi preservada; o empacotamento apenas redimensiona a arte para os tamanhos do macOS e monta o ICNS.

Conceito: uma prensa vermelha de metal, com rosca prateada, comprimindo um pacote amarelo. Fundo azul arredondado, margens transparentes, iluminação suave, sem letras nem marcas de terceiros.

Prompt final:

Create a single polished macOS application icon for an archive manager called Tabajara ZIP. Original design inspired by the general classic file-compression metaphor: a golden yellow compact archive/package compressed in a chunky red metal bench vise, with a silver threaded screw and a small dark steel turning handle. Friendly premium three-dimensional macOS icon rendering, softly beveled materials, crisp bold silhouette legible at 32 pixels, slight three-quarter perspective, studio light from upper left, restrained highlights and small realistic contact shadows. Red, golden yellow and silver, matching a playful Brazilian parody brand. The vise and package should be recognizable as physical objects, with clean simple geometry and no clutter. Center the symbol on a full rounded-square deep navy blue icon tile with subtle tonal gradient; tile occupies about 90 percent of the square canvas with transparent margins and softly rounded macOS-style corners. One icon only, front-facing tile, square 1024 by 1024 composition. No lettering, no ZIP text, no wordmarks, no watermark, no Windows logos, no exact copy of any existing application icon. Transparent background outside the rounded square tile.
